# 学习门禁（kid-tv-study-lock）

一个用于家庭教育的 Android TV 应用：孩子开机需要先回答课本题目才能使用电视，观看视频过程中每满一段时间会弹出题目，答错追加新题，全部答对才能继续观看。家长可随时通过密码合法放行。

## 功能

- 开机答题门禁：开机自动弹出全屏答题层，答对方可使用电视
- 观看弹题：监听视频类应用使用时长，每满设定时间弹出答题
- 防绕过规则：答错 1 题追加 2 道新题，本轮全部答对才放行
- 题库管理：家长通过浏览器在局域网内录入、批量导入导出题目，数据全部保存在电视本地
- 家长通道：家长凭密码解锁，支持按时长放行与远程解锁
- 隐私：无需联网、不上传任何数据

## 构建

仓库包含 GitHub Actions 流水线，推送到 GitHub 后自动在云端编译，构建产物为 APK（Actions 页面 → 最新运行 → Artifacts 下载）。

## 安装

APK 放入 U 盘，在电视上通过「电视卫士 → 应用管理 → 极速安装」安装，按应用内引导授予悬浮窗等权限。

## 说明

- 不刷机、不 Root、不替换系统桌面，卸载应用即完全恢复
- 家长解锁方式与默认密码请在应用主界面查看，首次使用后请立即在管理页修改
- 题库为空时门禁自动失效，应用异常时自动放行，不会导致电视无法使用
