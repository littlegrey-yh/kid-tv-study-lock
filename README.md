# 学习门禁（LearningGate）

Android TV 学习门禁应用：孩子开机先答题、看视频每满一段时间弹题，答错追加题，全部答对才能继续。家长凭方向密码随时放行。

对应需求文档：`../学习门禁App需求文档.md`（当前实现范围 = v0.5 MVP + v0.8 监控骨架）。

## 功能（v0.5）

- 开机答题门禁：开机自动弹出全屏答题层，答对方可使用电视；关机重启也绕不过
- 题库：手机浏览器访问 `http://电视IP:8765` 录题（单选/判断），支持 JSON 批量导入导出
- 题库为空时门禁自动失效，不会把孩子锁死
- 家长解锁：门禁界面**长按 OK 3 秒** → 输入方向密码（默认"上上下下左右左右"）→ 选放行时长（30分钟/1小时/2小时/今日）
- 远程解锁：手机管理页输入方向密码一键放行
- 观看监控（骨架已就位，设置页可开启）：监听视频类 App 前台时长，每满 10 分钟弹出答题

## 构建（GitHub Actions 云编译，本机无需任何环境）

1. 在 GitHub 新建仓库，把 `learning-gate/` 目录内容推送上去
2. 打开仓库 **Actions** 页 → 等待 "Build APK" 跑完 → 下载 artifact `learning-gate-apk`
3. 得到 `app-debug.apk`

## 安装到雷鸟电视

1. APK 放入 U 盘 → 电视「电视卫士 → 应用管理 → 极速安装」
2. 打开「学习门禁」App：
   - 点"① 授予悬浮窗权限"（必须）
   - 需要观看计时的话点"② 授予使用情况访问权限"
3. 手机浏览器打开电视上显示的管理页地址 → 录几道题
4. 管理页「设置」里打开**门禁总开关**（默认关闭，防止误锁）
5. 重启电视验证：出现答题门禁 → 答对 3 题进入系统

> 建议先关闭"门禁总开关"试用 1-2 天（只测弹题和远程解锁），确认一切正常后再打开。

## 安全说明

- 不刷机、不 Root、不替换系统桌面，卸载 App 即完全恢复
- 门禁界面所有按键被拦截（含 HOME/返回），退出只有三条路：答对、家长方向密码、远程解锁
- 题库为空 / 服务崩溃时自动放行，不会把电视变砖

## 目录结构

```
learning-gate/
├── app/src/main/java/com/family/gate/
│   ├── GateApp.java              # 应用入口：管理服务 + 监控 + 门禁兜底
│   ├── GateService.java          # 核心：全屏悬浮窗答题/家长解锁
│   ├── WatchMonitorService.java  # 观看时长监听（每15秒检查前台应用）
│   ├── BootReceiver.java         # 开机广播
│   ├── QuizEngine.java           # 答题引擎（答错追加2题规则）
│   ├── Db.java / Question.java   # SQLite 题库
│   ├── Prefs.java                # 配置存储
│   ├── AdminServer.java          # 局域网 HTTP 管理接口
│   └── MainActivity.java         # 电视端状态页 + 权限引导
├── app/src/main/assets/admin.html # 手机浏览器管理页
└── .github/workflows/build.yml    # 云编译流水线
```
